## 一句話總結
這是一份從 Claude Code 發行包的 source map（`.js.map`）逆向抽取架構後，整理成 18 章的工程分析書，重點是可移植的 Agent 系統設計模式，而非重製原始碼。

## 你可以學到的核心主題
- 代理迴圈：以 `AsyncGenerator` 串流輸出、執行工具、做錯誤復原與上下文壓縮。
- 工具執行管線：從模型請求到工具結果的多步驟流程，涵蓋權限、安全分區與並行策略。
- 多代理協作：子代理分工、協調者模式、共享提示快取前綴以降低成本。
- 記憶系統：檔案型記憶 + LLM 召回，而非只依賴 embedding 搜尋。
- 效能工程：啟動延遲、token 使用、上下文視窗、渲染與搜尋優化。
- 擴充與安全：技能（skills）兩階段載入、hooks、設定快照防注入。

## 目錄導讀（18 章）

### 第 1 部：基礎
1. AI 代理架構：六大抽象、資料流、權限與建置系統。  
2. 快速啟動管線：初始化階段與信任邊界。  
3. 狀態管理：雙層狀態、黏性閂鎖與成本追蹤。  
4. API 對話層：多供應商、串流、錯誤復原、提示快取。

### 第 2 部：核心迴圈
5. `query.ts` 代理迴圈：四層壓縮、token 預算與恢復機制。  
6. 工具系統：工具介面與執行路徑。  
7. 並行工具執行：依風險等級切批並行。

### 第 3 部：多代理協作
8. 子代理生命週期：`runAgent` 流程與內建代理型別。  
9. 分叉代理與快取共享：位元組完全相同前綴達成快取命中。  
10. 任務協調與群集：協調者模式與訊息傳遞。

### 第 4 部：持久化與智慧
11. 記憶：跨對話學習、分類與過期策略。  
12. 擴展性：技能與生命週期 hooks。

### 第 5 部：介面
13. 終端 UI：渲染管線、雙緩衝、物件池。  
14. 輸入互動：按鍵解析、快捷鍵、Vim 模式。

### 第 6 部：連接性
15. MCP：工具協定與傳輸方式。  
16. 遠端控制與雲端執行：Bridge / CCR / 上游代理。

### 第 7 部：效能工程
17. 效能：毫秒級啟動與 token 最佳化。  
18. 結語：關鍵架構賭注與可遷移知識。

## 10 個可直接借鏡的工程模式
1. `AsyncGenerator` 當 Agent 主迴圈。  
2. 推測性工具執行（邊串流邊啟動唯讀工具）。  
3. 安全分區後的併發批次。  
4. 分叉代理共享前綴快取。  
5. 四層上下文壓縮（逐層降成本）。  
6. 檔案記憶 + LLM 回憶。  
7. 技能兩階段載入。  
8. 黏性閂鎖維持快取穩定。  
9. 槽位保留（預留輸出空間）。  
10. hooks 設定快照（抗注入）。
